# EduCore V3.0.5 — Record Icon

This build replaces the previous EduCore/Mathside-style brand mark with the approved paper-and-pen record icon.

Updated locations:
- PWA / Android install icons (192, 512, maskable)
- Apple touch icon
- favicon
- public landing logo
- loading logo
- authentication logo
- teacher sidebar logo
- student app logo
- subject-logo aliases, so the old E/Mathside mark does not reappear after subject login

The main EduCore indigo/violet theme remains unchanged. No database or SQL changes are required.

If the old installed icon remains on Android, remove the installed PWA and install EduCore again after deploying this build.

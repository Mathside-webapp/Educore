ARCHIVE ACTIVITY

Archive this activity?

Before archivingEduCore will download an Excel archive containing the activity summary, student submissions, scores, and answer details. Students can still view the archived activity, but they cannot upload or submit anything to it.
!

CLEAR STUDENT SUBMISSION

Clear this submission?

This removes the current responseThe student’s submitted answers, score, feedback, and uploaded work image will be cleared. The activity itself is not deleted, so the student can submit again if the activity is still open.
⌂

END OF TERM

Archive this class?

Important — activities will be removedEduCore will first download an Excel archive. After that, every activity and its submission records for this class will be deleted from EduCore. Students will keep their accounts and remain listed in the archived class so you can import them into a new class without creating new accounts.
